Install by USB drive

          
These boards install firmware by copying one file onto them, like a USB stick.

          
    
            
  1. Put the board into its bootloader with the button below, or double-tap its RST button.
    2. 
            
  2. A drive named RAK4631, NORDIC or similar appears on your computer.
    3. 
            
  3. Download the firmware, then drag the .uf2 file onto that drive.
    4. 
          

          

            
            
          

          
Pick the board's port when asked; it reboots as a USB drive with no button pressing. If nothing happens, double-tap RST instead.

          
The board restarts the moment the copy finishes, so your computer may say the drive was ejected or the copy failed. That is expected and means it worked.

Before you start

          
    
            
  • Use Chrome, Edge or Opera on a computer.
    • 
            
  • Use a USB cable that carries data, not a charge-only one.
    • 
            
  • Close other serial tools such as the Arduino IDE.
    • 
          

          

            The board won't connect
            
Put it into download mode: hold PRG (or BOOT), tap RST, release PRG, then try again.
